GitHub Pages & content guide
  1. Add this file to your GitHub repository as index.html.
  2. In repository Settings → Pages, choose your publishing branch and the folder containing this file.
  3. Use this editor to add real projects, news stories, photos, videos, and team members. Use “Manage entries” to remove examples.
  4. Click Download updated index.html and upload that file to replace the repository copy. Your changes become public after GitHub deploys.
  5. Images up to 3 MB are embedded into the exported HTML. Videos use an HTTPS YouTube link or a hosted MP4/WebM URL. Store larger media separately and paste its public URL.

No passwords, API tokens, or private information belong in this public file. Browser drafts are optional and may be cleared by your browser. Export a copy to keep your work.
